# Contribution Checklist

Before opening a contribution that adds an Intelligence, provider, skill, agent, or external artifact:

- [ ] Human owner/maintainer is identified.
- [ ] Provider/project identity is recorded.
- [ ] Provenance and authorship are documented.
- [ ] Applicable license and terms are reviewed.
- [ ] Capability claims are evidence-based.
- [ ] Required permissions are documented and least-privileged.
- [ ] Security/privacy/rights risks are reviewed.
- [ ] External code is inspected before execution.
- [ ] Untrusted execution is sandboxed.
- [ ] Human approval requirements are documented.
- [ ] Tests or validation evidence are included.
- [ ] Rollback/removal path is documented for consequential integrations.
- [ ] No secrets or sensitive personal information are committed.
