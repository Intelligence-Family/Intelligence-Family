# Federation Security Controls

Security is a continuous control system, not a single check.

## Defense in depth

1. Identity and provenance verification
2. Explicit least-privilege authorization
3. Capability and scope isolation
4. Sandboxing/testing
5. Policy enforcement
6. Human approval for consequential actions
7. Audit logging
8. Anomaly detection
9. Credential rotation and revocation
10. Fail-closed behavior

## Harm-prevention principle

The Federation must not intentionally design, authorize, or deploy Intelligence capabilities for harming people. Safety constraints take precedence over capability, speed, or convenience.

This is an engineering requirement and must be reflected in implementation, testing, governance, and incident response.
