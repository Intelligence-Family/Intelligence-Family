# Security Policy

Security is a foundational requirement of the Intelligence Family Federation.

## Core rule

Human safety takes precedence over capability, speed, convenience, autonomy, and system objectives.

## Security requirements

- Least privilege is the default.
- Credentials must not be committed to source control.
- External agents require explicit, scoped, auditable authorization.
- Consequential actions require appropriate human approval.
- Missing or ambiguous authorization must fail closed.
- Security incidents must be documented and reviewed.

## Human control

CI validation does not authorize consequential actions. Human authority remains final.
