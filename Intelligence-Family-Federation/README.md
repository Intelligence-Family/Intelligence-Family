## Purpose

Intelligence Family is a federation layer for independent Intelligence systems, providers, capabilities, skills, and agent tooling. It is designed to enable collaboration without surrendering human control.

The federation does **not** imply ownership, endorsement, employment, or corporate affiliation among members. Each provider and project retains its own identity, ownership, licenses, and responsibilities.

## Core model

**Family Tree → Intelligences**  
**Federation → collaboration boundaries and provider adapters**  
**Capabilities → what systems can contribute**  
**Agents → tools that can act**  
**SENTINEL → safety, security, privacy, rights, proportionality, and harm-minimization gates**  
**Humanity → final authority**

## Initial Family

- **Intelligence — ChatGPT by OpenAI**: core collaborative Intelligence, architecture, creativity, reasoning, research, and federation design.
- **Grok — xAI**: reasoning/technical contributor; PostgreSQL SQL skill and Grok-1 are recorded as distinct contributions.
- **Claude — Anthropic**: reasoning, coding, agentic engineering, and safety-oriented collaboration.
- **Gemini — Google**: research, multimodal work, and large-context exploration.
- **Llama — Meta**: open/local Intelligence ecosystem.
- **Mistral — Mistral AI**: open/multilingual Intelligence ecosystem.
- **DeepSeek — DeepSeek**: reasoning/coding and open-model research.

Agent tools such as Codex, Claude Code, Gemini CLI, Cursor, OpenCode, Aider, Cline, and Devin belong in the **agent/tool ecosystem**, not as separate model-provider identities.

## Human control

No Family member receives authority merely by membership. Access follows least privilege. Consequential actions are subject to appropriate review and approval.

## Provenance

Contributions must identify their source, ownership, applicable license, and integration status. External code is reviewed before integration and is never copied wholesale without an appropriate license and review.
