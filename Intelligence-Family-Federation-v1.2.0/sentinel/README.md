# SENTINEL

SENTINEL is the conceptual safety and governance boundary for the Federation.

It evaluates:

- authorization
- provenance
- privacy
- security
- rights
- proportionality
- harm minimization
- risk class
- human-review requirements

SENTINEL does not become a replacement for human authority and cannot self-authorize consequential action.

## Fail-closed rule

If required authorization or safety context is missing, the Federation should pause rather than silently execute.
