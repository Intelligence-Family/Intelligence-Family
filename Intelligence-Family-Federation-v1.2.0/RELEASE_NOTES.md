# Release Notes

## v1.1.0 — Federation hardening foundation

### Added
- Explicit contribution and admission checklist.
- Human authorization and rollback requirements.
- Read-only default permissions for GitHub Actions.
- Dependency/action pinning guidance.
- Security reporting guidance.
- Adapter and capability boundary documentation.
- Decision-record template for consequential architecture choices.

### Preserved
- Human authority as the final authority.
- Provider independence and provenance.
- Least privilege.
- Auditability and safe failure.

### Deliberately not included
- Provider credentials or secrets.
- Model weights.
- Autonomous production execution.
- Automatic admission of new Family members.
